# workout-app

## Appearance

Use **Settings > Appearance > Dark mode** to switch between light and dark themes.
The selection is applied immediately and saved across restarts; light is the default.
Charts use theme-aware labels and subtle gridlines. Vertical gridlines appear in Week
and Month views and are hidden in Max view to avoid clutter.
Standalone calendar, clock, scale, and medication schedule icons switch to white in dark mode.
